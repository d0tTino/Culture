# Community Roadmap

Culture.ai is progressing through major milestones to create an emergent
multi-agent society. The roadmap highlights key phases and invites plug-in
authors to contribute.

## 1. Vertical Slice

The initial milestone delivers a functional vertical slice. Agents propose
ideas, share knowledge, and adapt based on relationships, memory, and
resources. This validates the simulation pipeline end to end.

## 2. Emergent Society

The next milestone grows the slice into a dynamic society. Focus areas
include richer roles, long-term memory, project collaboration, and a
persistent world. Contributors can experiment with new interaction modes
and explore how AI personalities evolve.

## Call for Plug-in Authors

Culture.ai welcomes plug-in developers to extend the system with custom
widgets, agent behaviors, or integration layers. See the guides in
[docs/plugins.md](plugins.md) and [docs/plugin_guide.md](plugin_guide.md).
This is an ideal time to share tools or visualizations that support the
emergent society milestone.
